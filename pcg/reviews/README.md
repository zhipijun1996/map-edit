# 视频观感记录

用户默认只看短视频，直接聊天反馈。收到具体意见后保留原话、A/B组与样例号、视频SHA、module SHA、问题、拟修改目标；证据类型video_observation。无需编造按键记录或要求先填网页。

当前真实观感评价0、手动试玩0、批准0。这个README不是用户评分。观察可指导可读性、等待、重复感和结构修订；手感、公平性与玩家成功率不能仅凭自动回放填写。所有修改重验并另录新视频。

原feedback_cli处理的manual_attempts仍是不同证据类别，不把视频记录塞进手动试玩store。设计返工可带source_kind=human_video_review及原话引用进入人工策展任务，再用固定物理全验；未知/主观问题先保留设计假设，不用无关参数冒充修复。
