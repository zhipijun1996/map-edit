# Current Module output contract

The required geometry/interface model is [MAP_FOUNDATION.md](../MAP_FOUNDATION.md). The production workflow is [pcg-module-production](../.agents/skills/pcg-module-production/SKILL.md), with [consumer instructions](../docs/module-package-consumers.md).

One stable ID has one current source record. Design-only, retained/implemented, native scoped qualification, portable runtime delivery and whole-map approval are distinct. The catalog is generated from records. A distribution is generated from qualified current sources, with explicit package/schema/Foundation/source versions, file checksums, footprint/origin/Ports/directed routes, ability/initial configuration requirements, allowed configurations and hash-locked host dependencies. Never substitute old raw cases or a preview for this interface.

Only explicitly verified orientation, connection subset, mirror, relocation and closure configurations may be offered. Public Port locations are boundary Block face centers; host standing anchors are internal adapter data. The host owns the existing player, stable instance identity, lifetime and shared wallet. Module loading must not silently reset resources. Actual native evidence stays scoped; no load test grants arbitrary entry, seam, chaining or full-map certification.
