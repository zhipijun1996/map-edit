# N06 中庭双翼换桥：首周期 needs_design

原型两条路线的动作核心已经在真实 Godot 成立，但扰动可靠性未过原门槛，**0 新候选，未跑 full/held，不得入库**。这是一个保留失败的有界设计周期，不把 clean 视频当生产内容。

先从低西 A 跳射到中央 M 真落地回枪，在同一初态选择：左射空保留实桥、右空中击铃撤左造右，两边都实际落对应桥回枪，随后上小岸、普通跳到高出口。三个端口是低西入口与东西高出向，恢复底岸不是 Port。`api_v2.py` 为隔离研究接口，不代表已满足技术准入；其他四有向关系 UNKNOWN，第二空间未实现。

协议为 2 规则 / 80 probe。实际 52 次：首版 clean0/4（核心桥接已出现，随后跳时碰到固定小岸下沿）；第二版只修桥后控制和入口另一预设值，clean4/4，3枪4跳329/347帧；20预反例，24扰动。第二版左 mild2/6、moderate3/6；右 mild2/6、moderate2/6，不能进入原 full。没有换选择或调质量门槛。

14个扰动失败没有落到 M：名义轨迹第一落地中心543.5，M左缘544，缺少接收裕度。另一个右路失败成功落M，但+5.36°实际射线偏离远铃，打到底岸[745,989]，没有桥交换。这要求明确的新几何修订，当前两规则已耗尽；提案是 M 左缘扩大到480而右缘736保持、铃从[800,672]移到[800,560]缩短射线，**尚未实现或验证**。

原20反例有一次旧观察误拒绝：右路多付一枪在M上短反冲、重新落M，之后仍正式跳离并交换右桥，真实首次落右桥回枪、到同一出口。`semantic-audit-v1.json`保留旧拒绝和原raw。`policy_v1.py`按实际M离地阶段及下一真实支撑判桥，不按counterkind白名单，也不放松身体、血量、能力、目标或右桥状态。原始“ordinary-M-jump”模板另有前缀漏jump错误，其真实输入只是走下台，不声称已测长普通跳；`omit-branch-shot`保留了真实20ticks普通跳，其他直接/省桥控制也真实执行。后续周期必须修该反例模板，不能覆盖旧证据。
