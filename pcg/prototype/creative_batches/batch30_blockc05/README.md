# C05：Block128 三端口追台择岸

本目录是同一原移动站玩法的**新 Block 地貌规则**，不是给旧样品补元数据，也不增加玩法家族。只公开接口0的一份物理布局、A→B与A→C两条路线；接口1仍有原高庭近岸控制缺口。

玩家从低处西岸A登上原线性上升载台。在同一段真实乘行过程中，可提前回折，落内部窄岸后转到上方西岸B；也可继续乘行，到更高处向右起跳、射原选择铃，同枪反冲并互换近门/远门状态，抵达高处东岸C。两个去向共用全部地貌、实体、奖励和初态。B是实际上层西向后续通路，内部底岸与楼梯不是Port；没有另塞一条安全口。平台仍使用原两点往返、真实承载与原风铃启动/暂停；没有圆形轨道、新物理或自动停靠。

## 先解决的真实矛盾

原A/B/C身体高度620/262/182无法通过一次整体平移，使三岸都在±32px内对齐ground64网格。最小最大岸改动也要40px，而且会把两出口改为同高。保留原“远岸更高”的空间顺序，本规则明确整体平移dy21，并修改A岸顶−51、B岸顶+51、C岸顶+3；这超出旧有界终岸适配，按新规则、新版本、新校准处理。

初版8个clean都失败：升高A岸后，原起步铃实际埋入岸体，原弹丸被碰撞挡住，移动台没有启动。最后规则让**同一个原风铃**随A岸上移51px，再从新身体点实走到原接近段。全部底岸与恢复楼梯保留，未删除失败地貌；原移动路径、承载、惯性、射击和成对门行为不变。原始失败与两个预注册协议均保留，未使用第三规则或扩大80案例预算。

## 实际结果

- 总80个小样：v1失败8；v2 clean7/8，选择近岸控制1、远岸控制0后冻结；新mild12/12、moderate12/12。
- 两路线各18个精确反例，0个否决核心。3条合法同目标替代保留：可以省初次上台跳，也可以省近岸最后换顶跳，但仍实际乘上原运动载台。不是指定按键词序验收。
- 错过近岸离台段后继续乘行选远岸，以及真实漏射选择铃、被远门挡住落到原中心柱、补射再起跳到远岸，两种同世界试件各clean1+mild1通过；无资源重置、平台重定相或人物搬运。没有测试这两个试件的moderate，不能据此声称通用恢复。
- 新近岸更容易换顶，平台运动依然形成回折与继续乘行的去向选择；“上台必须跳”和“最后换顶必须跳”不再是本版本设计必要条件。
- 标准 Python/JS Block 预检通过；小样不替代原regular校准和独立留出，根任务另行运行入库。

`probe-receipt-v1.json`绑定全部run、源快照、压缩原件索引、失败、控制选择、真实Port及同世界观测。所有完整身体检查均使用预冻结所有权，未在扰动后增格。
