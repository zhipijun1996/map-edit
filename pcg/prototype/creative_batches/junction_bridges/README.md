# J03 交织双桥：真实规则与探针

最终入口 `rules_v3.py`。两种需求为宽中庭（1040横向、260层差）与偏心高庭（900横向、280层差）；原Godot静态岩体、移动、普通单跳与反冲，不新增物理能力。

每布局四个真实外接口，上下两层各西/东岸。A进入可上桥继续或降至下廊；C进入可下廊继续或从中庭升到上桥。高桥两岸中间留真实空隙，内部悬置台负责落失恢复，不标第五口。删除所有奖励仍有换层与方向选择，本版没有奖励事务。

每布局7个程序、6个有向关系：A→B、A→D、C→D、C→B、B→A、D→C，以及不重置世界的A→D→B。未列关系保持UNKNOWN，不宣称全互通、单向或自动拼装。

## 探针结果

- v1：14真实案例，10通过，4次低层升高不足。实际轨迹保留，未降门槛。
- v2：仅修改跳跃保持/同枪时序；14/14 clean与84/84 mild（±1帧、±2°）通过。
- v3：补全18/20个独立反例程序与源码/依赖元数据，24/24 moderate升层探针（±3帧、±6°）通过。
- 合计136例，预算220例、最多3个源码版本。小探针不替代完整regular校准与独立留出，根任务另行执行。
