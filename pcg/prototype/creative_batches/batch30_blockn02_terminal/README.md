## 预算和真实结果

本周期57/57个实际小样，N02谱系16+7+57=80封顶。原失败没有改写为后来的通过。

- 两高末端参数及一低clean共3例，所选高/低均完整身体通过；未选高参数仍失败。
- 新随机相位+操作扰动22例：高mild5/6、moderate2/5；低mild6/6、moderate5/5。**高路追接容错不足，不能由clean认定技术准入。**
- 32个精确强反例无同目标否决。右侧向右下射确实使人物左上回落原静P2，真实承载17帧并回枪，之后仍只能到低C，够不到高B；早普通跳上静P2后的方案也未到高B。判断先看实际目标和成本，没有用“不启动P2”词序自动拒绝。
- 两条P1普通跳到低C的省枪替代保留，代价是多一次真实跳跃。一个“故意射偏”程序实际仍命中并启动P2，按真实事件接受，不把counter标签当事实。
- 第一P2落脚失败不是最后B岸问题：4次高路筛选失败在脚面接近P2时，人物领先台心约120/192/157/123px；实际允许横向中心差仅100px。因此下一设计必须联合处理接收宽度、反冲方向和静铃无遮挡走廊，不能只把台加宽再挡住铃。
