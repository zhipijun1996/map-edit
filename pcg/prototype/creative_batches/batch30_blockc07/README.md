## 小样与修订

总71/80个预注册实际小样，两版规则，全部来源/压缩原件索引在 `probe-receipt-v1.json`。

- v1四clean仅控制2满足原强反冲接触要求；冻结后mild6/6、moderate5/6。另两clean控制真实到奖，但先碰墙横速为−260，低于名义强撞阈值−400，原目的失败保留。
- v1的一个2枪2跳合法替代实际完成任务并有袋面落地回充，但上冲29帧离开当时上侧拥有空间。没有把它改写为通过。
- 最后v2仅增加显式上方 `[128,-320,384,400]` 动作保留空域，支持已看到的付费多跳路线；不动任何实体/物理/阈值，也不占Port外邻格。重新跑四clean和同一12扰动，仍为所选控制clean通过、mild6/6、moderate5/6。
- v2重新18反例，0设计否决。两条真实2枪2跳路线通过，三条松轴替代仍真实碰新墙，不要求指定方向键词序。有限反例不证明没有其他解法。

名义2枪1跳仍保留原−400px/s强反冲、同枪世界变化、完整身体关门净空、实际新墙法线接触和后续袋面支撑全部要求。`counter_policy_v1.py`另外根据真实Motor接触、−260→0横速、同枪先关墙、实际袋面落地及奖励/资源，承认温和碰墙替代；不按标题或counterkind放行，也不豁免任何身体越界。原强撞失败不被改成名义通过。

## 恢复的明确缺口

全部原恢复地面、左右台阶都在，没有删除失败地貌。漏第一枪后落底，经原右侧两台阶到奖，实际仍能3枪3跳完成；但上岸41帧进入B端口外邻格 `[6,3]`，所以**不符合本地Block恢复合同**。不能把这个格加进拥有空间，否则B不再是真边界。

随后独立试了两个左唇控制：775没有越界但最终到奖失败；780到奖但33帧仍越界。两次clean失败后没有跑多余扰动、没有扩大mask或添加第三规则。当前Block本地漏射恢复返回 `needs_design`；需要新的内部恢复路线或另一个Port/地貌设计后重新验证。真实物理到奖与Module所有权通过分开记录。
