# C04 / C06 独立设计证据审查

本次只读源码、真实 Godot raw、失败回执和旧候选；新增物理案例 0，没有修改实现。没有 C04/C06 视频可看，未作节奏或画面评价。人工批准、试玩与生产认可均为 UNKNOWN。SHA、实际动作和对照见同名 JSON。

C04 不应仅因地面预开解存在就被判为无聊；原“空中同枪反冲必须参与”的承诺确实被推翻，应保留这份失败。两个方向各五条地面预开加普通跳，都以同样 1 枪 1 跳、HP5、12 币、A开/B闭完成，最快 114/109 帧还略快于名义 120/116 帧。不能继续宣称空中射击必要。

但掩体的世界因果是真实的：A/B 分别遮蔽原敌人，暴露对照掉血；六条已发出的原弹丸实际在关门处 spent，原攻击源仍 active 且弹丸寿命未尽。接口 0 到新位后再开 B 会掉血，新掩体不是无效装饰。合法地面解本身也有原反冲：接口 0 开枪首帧 x80→70.3、vx约-583.5，暂时退出敌人的 180 激活距离，随后普通跳跨过真实攻击周期进入新掩体。这仍有“放弃旧遮蔽、把遮蔽搬到接收处”的空间目的。

建议保留为明确修订的 cover-relay 交互方向，允许地面准备和空中转移；不把它计为新独立反冲家族，也不把原 air-only 失败改称通过。下一版写清修订目标，原 regular 校准/留出照常执行，实际奖励/安全/机关后果等价的替代解应接受。不要加无意义的入口等待，只为让 old_cover_frames 大于零：瞬时地面枪在首个 post-action 帧就已把人推离旧位，缺少旧位帧不证明初始掩体不存在。两接口适用的接收处暴露、失误恢复及影片节奏仍需分别补证。目前仍是 0 候选。

C06 更适合归为 P50-G16“单枪投资高路或低风险分流”的有用 stateful adapter。旧实际候选没有任何 latch；新案一枪在真实坠落中将 vy800 改为约-1000，并打开高口、关闭低口，状态在失误后持续。这是实际新增的承诺/恢复关系，足以保留作可复用分支内容，尚不自动认定独立新家族。

两条选择确实共享同一个初态。高路 0 跳 1 枪到 12 币 B；低路 0 跳 0 枪到 6 币 C。低口不是把内部失误地面改名：C 在 Platform2，失败承接地另为 Platform3。宽井中，过晚高路枪仍关掉低门，落底后不恢复会被真实门挡在 x约348，拿不到低奖；恢复低门再跳/反冲，可在 242/243 帧达 C。同侧窄井也有“往错侧坠落后再补救”的真实对照，恢复后 255 帧达 C、不恢复失败；它不是所有正确方向迟射的通用恢复证明。

因此 C06 不是只有额外安全口的静态高低跳台，但艺术路口适用性仍需看图和影片、再由 Map 的实际职责验证。当前原始 batches 合计 220 探针，74 条反例包含合法射击窗口替代，不能写成“74 条全失败”。宽井恢复小扰动与窄井 clean 对照也不能替代完整门槛。所有请求方向必须继续原 regular 校准与独立留出，其余有向关系、通用回程和永久单向结论保持 UNKNOWN。目前仍是 0 候选。
