# 核心体验独立审查 v2

这是当前 Codex 独立模型审查，新增物理案例 0；不是人工观感、试玩、趣味批准或技术准入。逐文件 SHA、实际帧和未完成项见同名 JSON。旧报告与旧原型保留。

D03 的资源后果已有真实对照：先取东奖后，敌人自然剩 1HP；测试的西侧空中策略失败并落到安全下岸，只取得东奖；分段落脚策略取得两奖，敌人仍是 1HP。这补足了旧片里“故意杀敌才演示恢复”的缺口。有限策略失败不证明其他捷径不存在。最终 v8 几何仍需独立重绑；旧 v5 录像不能替代它。入口镜头仍看不到两侧奖励，且东奖容易被 UI 遮住，须修共同可见性。两侧空中与分段路线的实际成本、为何值得把命中机会分给西侧，仍须说明。

D04 旧 clean 数据确有同台停位改变后续动作：接口 0 中位返回原 A 为 3 枪、2 跳、286 帧；奖励侧取 12 币返回为 7 枪、6 跳、701 帧。不是单纯走路，但这两者外在奖励不同，不能用这组数字自证平衡。必须继续测试“中位停台→主动去 C 取同奖→回 A”的完整任务；比较器忽略最终指定停位，防止靠目标字段把廉价绕法排除。当前没有查看 D04 影片，节奏与可读性不作结论。

D05 发现核心被固定台替代：实际原生轨迹第 108 帧空中射击、111 帧启动平台；第 147 帧先落到固定 Platform2，空中枪已恢复为 1；第 167 帧才落到移动平台。因此现片确有真实移动接人，但并非用户要求的“移动台接住第一次落点、在台上恢复再起跳”。现有 purpose 只找后续任意乘台，会漏掉该偏差。应保留失败，修真实几何，使首个射后支撑与首次 0→1 回枪都发生在 catch-deck，再测提前地面开动、乘台后发射、多打一枪绕接台，以及不重置世界的失误恢复。铃在台上方 120 单位，纯表现上也应加清楚的连接/随动提示。

本次实际抽看 D03 每 0.5 秒 18 帧、D05 每 0.25 秒 22 帧，并读其原生帧与实验 raw；不声称真人操作或完整动态观看。当前原型不计入新增 30 件交付，最终人工趣味仍为 UNKNOWN。
