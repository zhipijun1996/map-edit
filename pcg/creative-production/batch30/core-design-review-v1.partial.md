# 核心体验独立审查（进行中）

当前仅审D03 v5原型；D04/D05等正常速度影片与最终来源后补。不是人评、生产认可或最终候选验收。

D03在实际数据/抽帧里确有“空中借火耗敌HP→到东岸取宝→回程击杀→改走分段落地去西岸”的世界后果，不能归为J06式空走。但默认镜头起始只展示右岸，另一奖励不可见，右高处还受UI遮挡，因此资源分配的选择不易先读懂。建议先修共同可见性。

单条预设序列没有证明两侧分配都有值得比较的价值：两奖励同为12币、路径接近对称而东岸更近；仍应比较同外在目标下的两种分配、残血/死亡后的动作成本。故意杀掉最后1HP可以展示恢复，却不能单凭这一幕宣称玩家需要作两难。

实际查看18个0.5秒间隔抽帧并分析465帧状态与事件，没有声称完整动态观看/真人操作。技术扰动失败由原实验保持，本审查不替它通过。完整来源和逐项可证伪建议见同名JSON。
