## B31-N06 中庭双翼：留旧桥，还是换另一翼

低处入口进入中央固定台，左右两扇水平桥翼与两处高外接岸同时可见。左翼实、右翼空；铃连着两翼，切换会同时撤左、造右。

一枪既决定身体向哪侧上升，也决定哪个后续落点存在；选择改变中庭两翼的可用支撑，不能同态兼得。左路允许向空处射击，不能强制也击铃。

不可丢：
- 同一中央M资源状态下两个真实去向
- 右翼必须实际由原pair切换生成，并真实接住本次跳者
- 两分支第一次中继落脚分别为L/R实桥，实际恢复后继续高岸
- 没有新增低安全Port或零枪走路分支

概念尺寸 1280×1152 / Block128；保留格不是实体外框。
- A W anchor [0, 704] / 内侧身体 [24, 718] / floorY 736：lower common ingress。
- B W anchor [0, 64] / 内侧身体 [24, 78] / floorY 96：west upper continuation。
- C E anchor [1280, 64] / 内侧身体 [1256, 78] / floorY 96：east upper continuation。

资源：入口可一段跳射到固定M，落地正常回充；再选L/R支撑，每次新枪来自真实落脚。所有中间落地如实记录，不能把枪数目标当趣味。

奖励：两外接高岸各有同等明确后续地理去向，货币可等额或另编无奖。桥翼不放奖励来强迫踩桥，是否必要由真实目标反例决定。

恢复：两翼下方原宽底岸/短梯回M或A；世界保持所选翼状态，重试先读当前哪翼闭合。不重置或赠枪。

方向：先A→B/A→C，其余4对UNKNOWN。可另做东侧低入口D，但它必须独立进入、实际到同一决策点后两分支成立才升4port。

廉价解与反驳：
- M一枪直接到高岸而省翼落脚
- 普通跳就可到两个高岸
- 右翼从未生成却落固定岩唇也判成功
- 左路命中铃只是目的词要求，射空等价被误拒
- 回收地改名第四口
- 上下岸外侧绕行/越出owned格才到目标

具体旧库对照：C01是唯一前向旧桥换新桥；本案在共同M决定保留或切换哪一翼，朝两个真正外接方向展开。无运动相位等待；是支撑交换的fork新空间组合，不自认新基本家族。

首次实验：先只从M同资源测L/R各2控制，射后首落实桥/实际回充与上岸。若M可同成本直达高端口，退回几何，不用必须落桥的标签掩盖；核心通过后再补A接近/恢复。

预算建议：建议2rule/80probe；静态支撑宽256，单段升高128–192，留出前冻结，不追304极限。

## B31-N07 中庭半环：现在离台，还是绕柱重接继续

单台从低层沿中庭右侧上升，一条可见锯线横过台的通行层。西侧避让台可以向东中层通路离开，也可绕中柱上沿重接同台去西上方。另一西中口正从避让台方向进入。

玩家暂时放弃同一真实移动支撑，让它穿过危险；固定地貌给选择窗口。继续路要从运动后的新高度再接同台，另一支则主动退出换乘过程。启动/暂停仍是原能力，不新增停靠。

不可丢：
- 同台离开危险前后support_id一致、实际位移连续
- 至少A进入时同一避让点可选择C或重接B
- D是中层真实进入方向，另验后才算第四口
- 两个去向不是锯下回收地与主路二选一

概念尺寸 1280×1152 / Block128；保留格不是实体外框。
- A W anchor [0, 832] / 内侧身体 [24, 846] / floorY 864：lower entry。
- D W anchor [0, 448] / 内侧身体 [24, 462] / floorY 480：mid-refuge entry。
- B W anchor [0, 64] / 内侧身体 [24, 78] / floorY 96：high continuation。
- C E anchor [1280, 448] / 内侧身体 [1256, 462] / floorY 480：mid-east continuation。

资源：在台和避让岸都只用真实接地恢复；选C和B实际支付不同离台/追接动作。不继承未证台速。

奖励：东C是中层外接，西B为高层外接；去掉奖励仍保留不同后续通路。可见货币位置不承担强制离台判断。

恢复：错过同台后下落内部宽岸；台保留运行状态，重登机会必须较短。若只能站等整圈或长期等锯相位，观感暂扣而不靠升危险救案。

方向：请求A→B/A→C，并在核心后验证D→B/D→C。B/C返向、A↔D和外部phase全UNKNOWN；四口12对不默认互通。

廉价解与反驳：
- 一直站台直到出口且无危险后果
- 根本不用重接也同成本到高B
- 避让点只是一个额外安全外口
- D新建场景换了台相位才可选
- 用两台替换同台追接
- 过长原地等待、隐藏自动停靠

具体旧库对照：明确把退出当前换乘与继续绕中庭重接作为一个可见决策过程，并增加从避让层进入的另一地域职责；是G07+C05的有用四口组合，不因4port称新家族。只有一台受控起始停泊，避免N02独立P1相位+P2启动的双参考窄追接。

首次实验：先一入口一台，实离避让与同台重接，锯前后有足够宽跳落区；再验证从避让点直接C。不稳时先减少请求为真实3port，不把未验D算作完成。

预算建议：建议2rule/80probe，先3port再第四进入方向；主运动过程约8–12s目标，长等即设计退回，非人评评分。

## B31-N08 折页回廊：取奖走上层，回来看见下层桥

A能看见上层闭合桥L与下层空桥R、上层绕柱宝箱及B出口。到B后回看，能直接看见原下层空桥的轮廓和控制两层的access铃。

同一次返程枪既将身体朝下/回内腔改轨，也把曾经的高路支撑交换成低层归途。资源站和奖励保留在同一世界，不重建一张回程图。

不可丢：
- 真实去程+宝箱一次事务+同世界返程
- 同一pair交换上下桥而不是补地图地形
- 新下层桥实际承载，不只是从旁边掉过
- 如果旧路反走更便宜，不能自称新回程是捷径

概念尺寸 1536×1280 / Block128；保留格不是实体外框。
- A W anchor [0, 576] / 内侧身体 [24, 590] / floorY 608：outgoing/return home。
- B E anchor [1536, 192] / 内侧身体 [1512, 206] / floorY 224：reward continuation。

资源：每段新枪来自实际岸体恢复；奖励只能取得一次；B已有资源状态连续带回，不刷新。

奖励：宝箱位于上层绕柱必经可见岸，B只是出口。无奖traversal请求不能偷偷靠必须取宝来声明上层必要。

恢复：各低落点以<=192px升高的小阶接回，不再使用C09一次大掉层后晚射勉强救回的几何。晚切换保留真实门态，返回能力仍单独验。

方向：声明A→B带取奖、B→A返程；完整A→B→A同世界是另一canonical。不会从两个fresh spawn单向证据推返回。

廉价解与反驳：
- 无奖低路被当同取奖目标比较
- 旧高路零额外代价反走却声称低桥更好
- 取宝时重置世界/资源
- 返程枪晚了落到下岸侧面
- 反向只fresh spawn通过
- 低桥根本未落脚

具体旧库对照：这是C09的Block先行紧凑修订，复用原空间与状态让上/下两层承担不同来回职责；不装成新基本机制。价值由完整录像和实际动作/时间/资源比较判定。

首次实验：先一份紧凑世界的去奖再回A全链，所有升高<=192，按真实位置/接地触发，不能用固定等待掉到铃下。然后比较不换态旧路返程的真实代价。

预算建议：建议2rule/80probe，先完整闭环1条，不为两个fresh成功就扩两尺寸。

## B31-N09 迎面而来的门：移动开口与身体相向穿越

上方原移动台当作机关轨，整扇门与铃一起缓慢横向往返。地形限制身体在窄而宽容的空廊中，目标岸始终可见。门移向自己时，铃的方向也改变。

目标既是控制器又随原轨道改变枪向；同一枪改变人物与移动门的通透，门本体继续运动。人不乘该台，不要求继承台速。

不可丢：
- 铃和真实门体同属原mount，实际移动包络都声明
- 移动门真实开后完整身体穿过其移动平面
- 不能只移动铃而门仍静止
- 平台轨道不新增反转/换轨/停靠行为

概念尺寸 1280×1152 / Block128；保留格不是实体外框。
- A W anchor [0, 576] / 内侧身体 [24, 590] / floorY 608：fixed launch bank。
- B E anchor [1280, 448] / 内侧身体 [1256, 462] / floorY 480：fixed receiver bank。

资源：单枪穿廊落目标岸，任何补枪必须有真实落脚。门相位可岸上观察，空中不靠极窄固定frame追目标。

奖励：门后固定岸可见宝箱；门是否移来改变操作，不用奖励标签强制命中。

恢复：漏射或错相位落内部底岸，保留运动与timer重试。闭门运动若推夹人、门parent移动造成错误碰撞，组合必须拒绝，不假装已经由旧mount验证。

方向：先A→B，B→A会面对不同门相位/枪向，UNKNOWN；不镜像继承。

廉价解与反驳：
- 等到无需射击也能绕门顶/门底
- 只把旧A3门的x参数换了就称新家族
- 平台与实际gate脱离
- moving StaticBody将身体夹穿却忽略
- 门只作为移动射线挡板而人物从未穿门

具体旧库对照：G08通过运动挡板选弹丸窗；这里身体要穿过开着且持续移动的实体门。是现有mount组合的未验证用途，不能宣称已实现可复用Cell。

首次实验：先仅验证mount后的真门/铃位置、闭门运动不夹穿、timed close本地坐标/身体保护与包络；可行后再一枪穿越。任何组合缺口返回needs_design。

预算建议：不优先，最多2rule/80probe；较短192px轨道和宽窗口，避免N02的双动态参考高敏感追接。

## B31-N10 趁近铃没醒，第二枪打到它后面的铃

同一窄而可读射窗后有前后两只铃：近A控制第一门，远B控制最终门。近A开后实际接收器暂时不再挡弹；玩家能看见它会随第一门关闭恢复。中间小岸可真实回枪。

第一个世界目标被激活后，**目标自身的弹丸碰撞消失**而露出后一目标；真实落地恢复要在这个世界窗口内完成。顺序来自真实拦弹/失活，而不只是程序要求先A后B。

不可丢：
- 两独立原ShotLatch，第一timed、第二可permanent
- 真实第一弹丸只击近A，第二弹丸通过其disabled碰撞击远B
- 第二枪先有中岸真实接地回充
- 近A复位后实际重新拦弹，错序/晚射有可恢复后果

概念尺寸 1280×1152 / Block128；保留格不是实体外框。
- A W anchor [0, 704] / 内侧身体 [24, 718] / floorY 736：first-shot ingress。
- B E anchor [1280, 576] / 内侧身体 [1256, 590] / floorY 608：far-door continuation。

资源：一空中枪，固定中岸真实恢复；不借敌人返枪，不给sequence虚构第二枪。地面提前开近A或多一轮准备是可能合法付费策略，不按动作词拒绝。

奖励：远B门后可见宝箱与真实出口，近A无独立奖励。用户看得见为什么第二枪打不到远环，不能只靠文字解释。

恢复：晚射重新命中A会真的重开它但不打开B；玩家落回宽中岸后可再准备，实际timer/资源连续，不软锁。

方向：先A→B；回程近环状态和永久远门状态改变，另验，不外推互换。

廉价解与反驳：
- 从其他射位直接绕近A击远B
- 普通跳直接越两门或绕侧
- 第一枪就同时命中两环
- 近环原碰撞其实未关闭/未恢复
- 用抽象sequence字段代替真实弹丸遮挡
- 中岸落地本身耗时过长导致只剩一帧窗
- 近门防夹一直延迟关闭被误当正常timer窗口

具体旧库对照：近目标的暂时失活给第二弹丸通行权，且这段窗口要容纳真实接地回枪。不是又一套两铃顺序标签；若真实近靶遮挡不能成立或任意顺序同成本，则按既有顺序机关适配。

首次实验：固定短射距先做三对照：近A活时射far被near截；开near后far弹实际通过；near复位再次截。然后才放身体两段。门/中岸要离原grow24区域，不能由防夹一直hold近环失活。

预算建议：建议2rule/80probe；所有靶尽量距发射处<=约200–230，给6deg扰动空间。timer初域约1.8–2.8s仅候选，按实际第一跳/回充/第二发飞行求解；不指定一帧。

N06/N07是真实选择/换乘节点假设：N06先3port，N07的D必须单独验进入与两个去向，不默认所有口互通。N08是明确旧案修订，N09是现有mount的未校准组合，不伪称已具备活动门包络与防夹证据。

入库仍走原WorkshopEngine、原regular/独立留出、标准generationContract及原持久化库。人工观感、试玩与生产认可分别UNKNOWN。
