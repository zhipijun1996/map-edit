# 范围与依据

按根 [MAP_FOUNDATION.md](../../../MAP_FOUNDATION.md)（规范）、[MAP_GENERATION_GUIDE.md](../../../MAP_GENERATION_GUIDE.md)（推荐）及[迁移skill](../pcg-module-migration/SKILL.md)执行。当前只迁移现有内容，先本仓库再主游戏；新增生产暂停，旧Map生成器退役。本skill不实现新Map、不续写创意批次。Guide的推荐Port数/尺寸/路线数不是硬门槛。

# 接口与可选用途

Module占据完整W×H正整数Block矩形，默认128像素可配置；内部地貌可以像素级不规则，不用凹形拥有格给其他实例让位，也不画强制外框。静态Cell、环境碰撞、封口在矩形内；运行中玩家/敌人/弹丸运动不等于矩形重叠。

Port在矩形真实外边BoundaryBlock外侧边中心，内部决策平台、恢复岸和身体dock不是Port。局部格(bx,by)的双倍边中心：LEFT(2bx,2by+1)、RIGHT(2bx+2,2by+1)、TOP(2bx+1,2by)、BOTTOM(2bx+1,2by+2)。格和face须真属于对应外边。

每口声明surface、face、初始INPUT/OUTPUT/INOUT及认证接口。ROCK仅左右且下方有安全实体岩体；ONE_WAY_PLATFORM四面可用且有安全可穿支撑；AIR无安全站地、按认证向下进入，底边不得有INPUT（包括INOUT进入）。顶部AIR OUTPUT无合法同类底边INPUT可接，不能当必需向上出口。连接必须同世界点、相反法线、同surface、权限兼容、有认证接缝，不能偷换类型或借邻居支撑。

**允许部分Port连接。** 模板总口数不必等于本次连接数；同模板可当枢纽、普通穿越或单口自环奖励，标签不锁用途。其余每口有本矩形内认证封口或天然封闭配置；少量伤害、装饰或仍可硬穿的荆棘不算封口。封多个口也不破坏必要Route、不产生新连接；相互影响的配置显式认证，不默认所有子集支持，也不强制全口接通。通向未连接口不产生外部边，封口影响的内部可行性按证据更新，不按规划删边。

# 有向Route与镜像

N口建立N×N矩阵含对角线，每格0或多条Route；逐条写起止、Block位移、静态必要能力、动作、难度、时长、资源、初始条件、动作接口及validation。自环表达同真实口进出/取奖返回，需兼容初始进出权限；不以内部marker循环假装自环。A→B和B→A独立，未测保持UNKNOWN，有限失败不证明绝对无路；同对正常/恢复策略不算多个连通对、模板或新家族。

同一布局各Route共用真实世界、机关初态、能力和奖励事务，不用不同重建世界拼成一次选择。初始单向权限不借用开门后关系；特殊开门后返回需完整离线结构认证。资源、速度、机关动作在原Godot离线/运行时验证；在线只用一次静态能力和初始权限，不逐步追HP/精力/速度/背包/开关，不LLM补Module。

水平镜像同base、只用认证方向；全部Cell/碰撞/Port/机关/方向行为与视觉一起映射。格x'=W−1−x、双倍边坐标u'=2W−u，左右face交换、上下不变；权限与Route起止身份不交换，矩阵不转置，不能代签反向。分别统计base、方向、版本、Route和用途。

# 审查空间选择，不加安全口凑数

先看原物和实际影片，再读设计名。用户对J03/J06“走路无聊、缺设计感”的反馈保留在 `pcg/feedback/workshop/junction-boring-observation-v1.json`；技术连通和AI“适合路口”不能覆盖人工意见。多口艺术来自可读构图和真实判断，环岛只是例子，不要求每路开枪或机关。

逐模板说明：

- 各来向先看到什么，何时知道去向，在哪里承诺选择；共同决策可是一点或沿路显露过程，不固定三口都从A分两口。
- 同一实际进入条件下，去向怎样改变动作、人物/世界因果、资源机会、风险或信息；保留不同来向不同选择、部分单向/汇流/换层，不强制全互通。
- 地貌空腔、地标、上下前后层次怎样支撑该判断；不以标题、装饰、堆刺或尺寸变化替代体验。
- 奖励怎样看到/取得，错过后怎样恢复，回程/汇入有何真实证据。内部恢复岸不因凑口数就命名成探索出口。
- 普通跳、省枪、提前开门、越顶、接地回充、相位等待是否达到相同目标。合理替代保留，必要动作被推翻就修正描述；仅剩普通挑战+安全侧口时明确体验差距，不造新家族。

单纯走路节点可能有地图用途，不自动算动作创意；同模板部分使用只是穿越也合法。AI去重/观感不替人评，技术合格不等于艺术认可。

# 迁移与认证

按迁移skill审真实场景/依赖，给最小修改方案，不另造玩法或框架。旧不规则边界Port、未知surface/权限、缺自环/封口/镜像、丢失构图分别列gap；包围盒重标不自动合法。修改后冻结版本，复用原Harness/角色/弹丸/资源/承载与原质量门槛，固定预算/选择/独立留出。

逐Route测完整身体、稳定出口、机制因果、操作/瞄准扰动和反例；逐连接子集验证保留路线与未用口不可非法越界、封口组合兼容。适用时测错过/恢复与同世界连续路线；fresh反向或单clean不签通用返回。发现额外真实Route要记录、补认证、进入实际图，不能因未规划就屏蔽。

最终目标为 `modules/`，确定性完全重复非代表/明确排除项按迁移记录去 `modules-recycle/`；近似待审、缺口和失败原处保留。只有目标验证、回读与引用完整后才归档原件。使用实际已实现的迁移CLI；不把工具规划或旧schema pass当新认证。

交付基础ID/版本、矩形、全部Port、N×N多Route、镜像、封口配置、源/物理/失败/留出与影片索引。在线实际图至少区分instance+Port，包含本次配置下全部有效Route及额外捷径；单Module不替代整图。三去向、技术结果、AI审查、人工观感、试玩及生产认可分开，不commit或发布。

# 角落Port不是额外分叉

按[角落Port扩展](../../../docs/l4-mapgen/corner-port-relocation-v1.md)逐口保存左上、右上、左下、右下四角迁移属性。同角落Block相邻外边中心可申请换边，位置互斥且逻辑ID不变，不当新Port、新Route或新创意家族。允许接口附近真实地貌/合法表面适配，但不删原有向功能、不扩权限、不添加绕过核心的安全路。多口换边、部分封口和镜像会相互影响，只开放已经联合认证的完整`portConfigurations`。UNKNOWN不可用于Map匹配，原配置仍可独立迁移。

旧默认朝向未认证时可按实际路线出流改到最近合法边，记录依据后重验；不能为RIGHT标签增加长安全底板。历史via若指内部奖励台，应明确命名为内部waypoint，保留真实地面到达检查，不把它强迫迁到新外边Port。端点、真实边界出入、内部选择节点与奖励/恢复台各自保留身份。
