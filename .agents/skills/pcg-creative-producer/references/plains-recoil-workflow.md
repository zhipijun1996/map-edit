# 平原：把样品工坊变成可反复使用的内容配方

当前用户优先级：先把平原做好。唯一特殊能力是反冲，保留移动与普通单跳。钩索、墙跳、二跳留作其他区域储备。已有敌人、风铃、移动平台、门与危险仍可用；平原可以安排跑跳、观察、战斗及机关，核心学习线围绕反冲。

先读 `pcg/prototype/creative_batches/plains_workshop/profile-v1.json`、同目录catalog入口、现有失败及用户反馈。当前20项已收到“大体上都是ok的”整体视频正向意见；不要继续把这批写作完全未获观感反馈，也不将它扩写成逐个评分、实际试玩或生产批准。

## 每张内容工单

先选教学、练习、组合、可选奖励、连续回程恢复之一，写清玩家本次学会/运用什么判断，再指定能力、完整身体空间、端口方向、资源、奖励与失败成本。教学只引入一个新关系；组合使用已经讲过的关系。兼容三能力的内容不一定在教反冲，例如原M07/M08见证无射击。

模型读取已有关系与失败，提出少量可证伪假设。一个假设转成一条有明确参数域的配方：因果不变量、Cell、几何域、可变控制、奖励、失败恢复、针对性反例、支持的空间/方向、缺口。先复用原Cell；未支持的条件明确返回冲突。后续空间请求调用相同配方，不为每个房间复制一份生成器。

程序继续使用原production_loop/WorkshopEngine/regular评价器/标准输出/CandidateLibrary。每需求固定4个控制候选、小筛后选1个；完整身体、实际机关/资源、廉价绕法、原regular校准和独立噪声留出不省略。合理替代操作允许。固定源码/规则域/预算后再跨空间试验，期间不修改代码，也不挑留出后的幸运参数。

新见证以新版本入同一候选库。平原catalog只按能力与设计职责给原库建视图，不复制第二个库或改变UNKNOWN。已知失效版本拒绝，长等待可暂扣；支持域外不能换成普通房间。新进程精确重检索，并用错误能力、错误空间和未验回程请求检查拒绝路径。合并旧库时一起保存原SHA依赖闭包，确保干净检出可以恢复并复用。

视频反馈进入现有feedback，以原话/视频SHA/版本绑定。正向意见用于保留，问题指导具体修订；参数/机关/形状/策略变了就重绑证据。实际试玩、人类难度和正式准入另记，不阻断候选迭代。

## 怎样判断方法开始稳定

分开记录：单个实例的噪声/相位容错、冻结规则对新空间的适应、跨进程复用、收到真实反馈后的可维护修订。前一种通过不能替代后三种。

后续方法实验应在冻结实现后，由独立需求制定者揭示多个规则的不同跨度/高差/净空/端口请求。预先固定支持域、可协商条件、预算、满足率目标及停止条件；每个入库实例仍须原regular门槛。记录实际满足/拒绝的需求和理由、人工返工次数、成本、漏过的廉价解法及反馈修订后的旧回归/新空间结果。本轮2规则×2新空间只是首次有界适配证据，不能称已通过盲空间泛化或稳定生产验收。

## 平原的下一批职责

1. 宽容的首次反冲教学：可见目标、清楚射向反馈、真实安全落地后重试。
2. 同一判断的练习：改变跨度、高差和落点，稳定产出并保留操作容错。
3. 反冲组合：依次接刹车/转向、同枪击铃、主动载台，控制一次新增的世界条件。
4. 可选奖励与资源取舍：宝箱先可见，取宝与汇回各有实际路线；敌人回充放在已理解空中资源之后。
5. 回程和失误恢复：不重建世界，继承资源与敌人/机关状态；普通返回和错过落点后的重试分别验证。
