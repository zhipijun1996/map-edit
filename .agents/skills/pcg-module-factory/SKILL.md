# 最小修改，不重造玩法

从现有真实地貌、机关、敌人、奖励与玩法关系出发，先清点依赖和既有证据，再给最小差距/diff。补字段不冒充动作认证；改形状、Port、surface/权限、机关、奖励、镜像、封口或策略就绑定新语义版本，重验受影响范围。不能通过删恢复岸、降门槛、放大范围、改名或强制动作救过；无法保住核心就返回待处理。

复用原动作生成、`WorkshopEngine`/factory Engine、质量档案、真实Godot Harness、源冻结、反例/校准/独立留出与原库。迁移CLI是薄编排而非第二物理、第二候选库或在线生成器。缺实现必须报字段/消费者/验证缺口，不能在skill里宣布支持。

# 新地基生成/修订约束

1. Module为正整数W×H的完整Block矩形，默认128像素可配置，实例矩形不重叠；内部Cell像素级，不整体缩放或加外框。静态布局/碰撞/封口在矩形内；动态玩家/敌人/弹丸运动不作为矩形重叠定义。
2. Port在矩形外边BoundaryBlock外侧边中心，实际身体dock另记。ROCK仅左右且有实体支撑；ONE_WAY_PLATFORM四面可用、有安全可穿支撑；AIR无站地、按认证向下进入。底边AIR无INPUT/INOUT进入权限；顶部AIR OUTPUT无合法同类底边INPUT，不能承接必需向上连接。
3. 每口显式初始INPUT/OUTPUT/INOUT。连接要求精确同点、相反法线、同surface、权限兼容及认证接缝；不默认外部速度、补平台或重置资源。旧ground profile不是新surface证明。
4. 允许只用部分Port，其余用本矩形内认证局部封口/天然封闭；只有伤害或装饰不算阻断。封口组合不得破坏必要Route，影响关系要记录和验证；模板口数不必等于本次连接数。
5. N×N有向矩阵包括自环，每格0或多条Route。每条保留起止、Block位移、能力、动作、难度、时长、资源、初态、进入/离开接口及实证；A→B不推反向，UNKNOWN不当无路，自环不自动改Port权限。多策略不计多个模板/连接。
6. 保留全部真实有效Route及合理替代，不因省略原设动作就否决同目标合法解；记录动作可选/体验冗余。在线实际图不得只保留规划Route；未认证通路迹象是迁移缺口。
7. 水平镜像同base、非转置；全部实体/碰撞/Port/机关/方向行为一起映射，权限与起止身份不交换。只启用认证方向，镜像不算新模板或反向资格。

# 原技术管线

先固定请求、精确版本、修改范围、实验预算、选择规则、相位/时机/瞄准扰动及独立留出；先静态与小样反例，再用原质量门槛完整验证，不以clean成功代替资格。源码冻结期间不改依赖或查询元数据；输入、执行、raw、源SHA与所有失败保留。零帧拒绝、真正步进、录像和静态检查分别记成本。

验证完整身体净空、原弹丸/反冲/承载/惯性/碰撞/防夹、真实资源与稳定出口，逐Route/方向/封口组合/镜像绑定。恢复、同世界返回和接缝按声明验证；单段或fresh满资源反向不代签连续条件。有限反例未找到绕法不证明唯一解或无路。使用[物理skill](../pcg-physics-contract/SKILL.md)和[视频skill](../pcg-video-review/SKILL.md)。

技术通过后按迁移skill回读目标、检查依赖/引用和可恢复归档，再处理原件。失败留原处，不先搬到回收。完全重复有确定性等价依据才归并/保留alias；近似待审。人工观感、试玩和生产认可独立，不伪造评分或批准。

预期迁移工具为 `python3 -m pcg.migration` 的 audit/inspect/validate/promote/archive/build；先核实际帮助、参数和覆盖，不把计划命令或旧生产入口当已实现能力。当前不commit、不发布，不实现新Map；以后在线仅一次静态能力/初始权限、纯程序读认证库存，不模拟逐步资源或调用LLM补内容。

# 四角接口适配与后续创作

迁移修订及日后恢复的新生成都按[角落Port扩展](../../../docs/l4-mapgen/corner-port-relocation-v1.md)输出逐Port的四角`cornerRelocations`，不事后只写“可旋转”。目标是同一角落Block相邻外边中心；可局部适配合法表面和支撑，但原核心挑战、奖励/恢复、必要能力/资源、初始权限及路线功能保留。原口与替代位置互斥，同逻辑ID，不增加模板数。未测UNKNOWN，不把ROCK垂直化或把底部AIR输入合法化。只有经过原真实Harness认证的完整配置可开放；多个换边/封口/镜像仅使用联合认证组合。可选配置失败不阻断原配置完成。

尺寸或端口不合规时执行通用适配，不仅返回needs_repair：真实占用/动作空间向外取整128倍数，先整体平移对齐，再改接岸和短连接；缺少已有Cell映射是补工具任务。批末更新索引，避免逐件重验已冻结旧库。

历史默认Port朝向只有设计提议、没有真实认证时，按实际出流和最近合法边适配，不为保留RIGHT标签铺长安全底板；记录方向修订并重验。内部奖励台/dock命名为内部waypoint，保留真实trace访问断言，不与外边Port混为一谈，不强迫无意义的外边往返。
