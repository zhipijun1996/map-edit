# Current Module production

This instruction replaces the historical design-session and migration-only work modes. Their original receipts remain available at Git commit `9b712fe814ef228b368c0eb9adf660e39de29e37`.

- The only editable Module library is `modules/<stable-ID>/`. Each ID has one `record.json`; implemented content uses `module.mapnote.json`, development designs use `design.json`. `modules/catalog.json` is generated. Never scan historical rounds or restore an old catalog into production.
- Read `.agents/skills/pcg-module-production/SKILL.md` for library changes or delivery. Read `MAP_FOUNDATION.md` for geometry/Port/Route rules. Reuse the existing native PlayerController, Cells, quality verifier and design renderer; do not create replacement physics.
- Keep human design decisions, implementation approval, scoped route qualification, portable delivery and Map/human-playtest approval distinct. Pending designs stay in this library and never enter runtime packages. Record conflicts in the affected `record.json.gaps`; do not alter approved designs without authorization.
- All official editor/workshop/update sources use `main` and the same generated catalog. Workshop data and thumbnails are derived views. Downstream consumers receive a versioned package, not a branch of experiment folders.
- Use `python3 -m module_pipeline add|update|review|qualify|withdraw|index|check|validate-portable|build`. The `update` transaction invalidates implementation/runtime approval and, for gameplay or runtime-contract changes, physics evidence. Metadata-only revisions may carry physics evidence through explicit content equivalence. Commit source inputs before a release build. A retired ID remains a tombstone and cannot silently reappear.
- Run `npm run check` and focused `npm run test:production` for pipeline changes. Run clean-package Godot acceptance when runtime, dependencies, source or compiler changes. Retain honest failure/scope information; a passing load is not a new robustness or whole-map proof.
- Historical originals are recoverable from Git or immutable archives. Do not reintroduce `library/`, `modules-recycle/`, multi-round implementation sources or old production CLIs. `build/` is disposable generated staging, not an authoring library.
- Respect the current user's authorization for commits, PRs, publication, merging and cleanup. Historical session restrictions do not override it.
