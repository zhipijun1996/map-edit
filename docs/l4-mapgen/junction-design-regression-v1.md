# J06/J03为什么偏离原创意

用户原话：“j06和j03都十分无聊，单纯的走路，没有任何设计感。和当初的5个创意输出为什么差距这么大？”[版本与影片绑定](../../pcg/feedback/workshop/junction-boring-observation-v1.json)。这是对交付的明确设计否定；不编造逐片观看范围、手玩报告或分数。四个版本保留技术证据，暂扣于平原优选之外。

## 选案阶段已经偏离

[原五案](plains-five-designs-v1.md)中，D01已被用户否决为基础关系重复；其余设计的价值来自具体矛盾：D02载台持续下降，玩家先退让净空、再抢离台高度；D03借敌人命中补给却消耗未来机会；D04这一枪确定回程支撑；D05打箱前进同时把身体推退。它们不是换个方向走，而是行动产生相互牵制的后果。

后续多口提案推荐J06/J03的理由明确写成了“不需新Cell，先验证静态空间构图”。根任务接受了这个排序，把实现容易、接口易验证放在核心体验之前。J06本来就是较弱的安静节点，不能把其缺乏动作判断全部解释为落地缩水。两案也不是D02—D05的完成版本；其选择离开了此前获得正向意见的创作方向。

## 具体缩水

|内容|提案中承诺的内容|实际交付|
|---|---|---|
|J06|不对称三角地貌、横生地标、围绕共同风口的方向展开|孤立高岸加连续阶梯；主过程为落下、向左走或重复跳台阶；地标与风口负空间没有实现|
|J03|空心双拱、错层编织、下廊台阶与中庭共同组织换层|四个矩形：左右上岸、一整块下层地面、一块小悬台；保留连通与一次抬升，空间承诺未兑现|
|审查|检查实际玩法、构图和玩家的判断|主要认可不同出口职责、共同状态前缀及有向路径；未拦住缺乏节奏、动作矛盾与构图的样品|
|交付顺序|先得到一个有核心体验的Module，再验证可复用适配|先做两种接口和大量技术验证，随后用技术成果描述交付；设计价值未成立就进入适配|

J03确有真实跳跃/反冲换层，不能在技术记录中改写成“所有帧都只有走路”；但存在一枪或一个高差不足以反驳用户对整体无聊的判断。无需增加枪数或危险来证明它有设计。

## 流程应改变什么

1. 选案先写不可丢失的体验、必要的地貌组织和可读后果，判断它是否值得实现；成本只能影响排期，不能替代设计价值。
2. 实现中维护原案→原型差异。核心因果或地标缺失就明确报告缺口，不能沿用漂亮标题当成已经落地。
3. 第一份小原型同时检查实际动作关系与空间组织。先不看标题，根据正常速度录像和世界状态复述体验；只有“左右/上下都能到”就回到设计。
4. 然后做不同接口、完整物理门槛和批次积累。仍允许合理替代，不强迫固定按键，不因某个特定射击可省略就一律判失败。
5. 人工否定必须影响后续检索与选案。原技术候选、历史AI审查与影片不删除，当前优选索引暂扣这四份版本，精确需求不能继续返回成优选内容。改造后另立版本与证据。

本轮进行反馈落库、方法纠偏与优选暂扣，没有新Module或新Godot实验。下一次实现应重新建立具体玩法与构图，不沿用本批技术数量来宣称改进成功。
