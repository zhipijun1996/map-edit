# 风隙回响：内容接入第一轮，以及与正式地图的三方对照

本轮修订的是上一轮用户反馈“看录像就觉得非常无聊，几乎就是到处走”的19 Macro整图。沿用 PR #1 / research/l4-map-generator，未改正式游戏流程。**这一轮完成了具体挑战的真实接入与整图复验，没有证明整图趣味超过主游戏，也没有完成最终区域目标。**

实际审阅入口为 `generation/maps/content-routes-review-v1/report.html`，含新图、当前正式图、主线完整录像、奖励挑战24秒片段及完整原片。发布记录见 `pcg/results/content-routes-publication-v1/publication.json`；原生原件在 `generation/maps/content-routes-v1/{main-native,reward-native}`，归档另保留所有失败和源快照。

## 做了哪些内容改变

仍为原R2生成的19地点、27处直接接缝和多条奖励/回程路线。Map新增地形0，不在Module之间塞短平台。四处需求在生成前写入 `content_routes/protocol.json`，由已有生产器的有界适配路径实现：

| 职责 | 实际内容 | 验证边界 |
|---|---|---|
| 入口引入 | 空中向后击铃，同一枪产生反冲、打开0.8秒通路门，穿过带尖刺的岩拱下方 | 实际开铃与穿越；有限省略/改角度策略失败。未证明所有高位绕路不可能 |
| 主线组合 | 空中命中真实哨兵，返还射击次数，再次反冲到远岸 | 实际敌人命中和射击资源；不是靠动作标签强制认可 |
| 出口前精度 | 原低岩拱跨越增加真实顶刺和谷底危险面 | 原角色身体碰撞、伤害与落点检查 |
| 奖励远征变化 | 支路引入同族限时通道，再进入原有斜向反冲宝库 | 明确是同族复用，不把第二个参数实例算另一种创意 |

保留两个实体宝箱、商人和原奖励服务。去程的敌人接力不是永久资源设施：回程从安全的远岸用实际射击击败哨兵，反向跨越；再次来访时观察真实死亡状态，靠近崖边后用一枪跨越。输入策略只发移动、跳跃和射击，没有复活敌人、传送玩家或补射击资源。

本轮内容实际为1敌人、4风铃门、7危险面、2宝箱、1商人、0移动平台。**四个修改Macro，不是四种全新玩法，更不是19种好玩挑战。**

## 为什么可能比上一轮好

1. 射击开始与世界产生因果联系：打开实际通道、伤害敌人并恢复空中行动次数，而不只是对着空处反冲爬升。
2. 空中目标、位移方向和危险净空同时影响操作。省略核心射击的有限策略在真实世界里失败，不靠“必须做动作”的目标标签拒绝成功。
3. 回程考虑世界已经改变。敌人被击败后的再次通行实际跑过，门重新关闭后的返回也保留原验证。
4. 尖刺与敌人经标准Module文档进入拼装。修复了共享拼装器遗漏危险面宿主索引重映射的问题，并为危险矩形平移增加检查；标准重读验证危险面宿主与几何，避免把标记当真正伤害。

不过，实测改善幅度小：

| 相同路线 | 上一轮 | 本轮 |
|---|---:|---:|
| 主线程序耗时 | 32.93s | 30.70s |
| 主线走路策略时间占比 | 43.12% | 39.03% |
| 主线实际射击 | 9 | 12 |
| 第一条奖励远征 | 72.55s | 72.55s |
| 第二条奖励远征 | 79.55s | 78.47s |
| 替代主路线 | 43.43s | 43.43s |

走路策略包括到达稳定，不是纯步行比例；更多射击也不等于更好玩。**第一奖励远征与替代主线基本未变，不能把入口与一处接力的改善外推成整图都更有趣。**

## 为什么仍比主游戏差，哪些地方可能更差了

| 维度 | 本轮研究图 | 当前正式图 |
|---|---|---|
| 内容组织 | 四处需求适配，其他多为原通行地形 | 远程顺序铃、受控渡台、荆棘落点、齿轮、反冲跨度等已有配方，按空间身份分配并避免相邻重复 |
| 规模与Seed | 19个研究Macro，一张物理拓扑 | 20个探索地点、59–63实例；五Seed有不同manifest和空间家族 |
| 生态 | 1哨兵，主要服务单一动作核 | 15–19敌人，与路线/环境共同构成压力 |
| 地貌与认路 | 仍大量水平层、薄岩廊和相似竖井 | 地标、区域身份与完整表现更充分；正式图自身仍有平台化问题 |
| 奖励与流程 | 2宝箱、1商人、隔离单图状态 | 4宝箱、正式资源/物品、商人、Boss、跨图流程 |
| 教学与容错 | 入口就叠加限时门和尖刺，失误恢复不足 | 有引入配方、安全落点和恢复职责；仍需真实体验评价 |

与上一轮相比也有代价：为了给敌人接力腾出真实头部净空，局部上层岩廊变薄，空间的自然感没有同步解决；尖刺提高失败压力，但还没形成充分的教学和恢复区。主动玩法密度提高了一点，整体地貌、多路线差异和战斗生态仍没有跟上。

通路铃目前只定义经过验证的低位路径，**不能冒称全局能力锁**。任意高位绕行、跨相邻Macro落入、所有进入资源状态尚未穷举。只有两个宝箱腔另用实际实体岩体、24×36身体扩张和闭门/开门几何搜索确认收益隔离。不能把门附近录像成功当成“所有路线必须开门”。

## 真实验证与失败

- 冻结整图：21/21，含13条名义/方向覆盖路线与8条独立±1帧/±1度输入扰动，并改变敌人初始待机时长。不是人类通关率。
- 全部50声明连接方向实际完成，包含稳定落地和真实脚底支持面。
- 10条简化策略均到达修改位置后失败：通道省略射击、改为向下反冲、长按跳跃变体；接力省略首枪/第二枪或改一枪水平；两宝库省略射击与延长跳跃。仅签这些有限策略，不签全局必要性。
- 两个实体宝箱闭门隔离检查通过；280静态对象、零Map填充、零未声明跨Module实体重叠，静态/门占地检查通过。
- 19版本进入原CandidateLibrary的隔离候选索引；热库19/19命中、生成调用0，重新跑5条整图路线全部通过。通用关系仍UNKNOWN，人工趣味与生产准入均0。
- 主线与奖励远征两段正常1倍原生录像，1842+4708=6550帧，与原物理轨迹逐字段一致，包括资源、敌人/门事件及经济回执。奖励短片明确截取完整原片27–51秒，不以片段代替连续原片。
- 浏览器手动消费检查通过：实际加载全19节点/280静态对象/6状态门，键盘移动、跳跃、射击、重试和整图查看；不冒充人类试玩。
- 原编辑器检查、43纯合同检查、L4 31项、Map35项、Factory26项、Plains19项通过；测试数量不是质量评价。

所有失败保留：奖励远征内容不在声明通路上、正式尖刺资源缺失、上层岩廊拦截接力飞行、反向先撞关闭门、回程跨距不足、哨兵仍存活的攻击、地面反冲把玩家推入谷底，以及敌人死亡后原起跳点过远。

预算如实记录：初始六次校准以12/13结束；随后登记两次专门回程策略修复，最后登记一次死亡世界起跳触发验证。它们都是留出前的有界阶段，未把初始预算冒充一次成功，也未从独立留出挑成功样本。独立留出只运行一次，之后没有修改内容/运行时源。

## 当前实现与成本

`pcg/map_directed/content_routes/run.py`复用原Mission/Exploration、现有固定接触布局、标准导出/重读、原拼装器、CandidateLibrary和Harness。`pcg/prototype/plains/content_routes.py`是现有动作核的有限适配器。支持域外需求直接返回缺口，禁止降级成普通平台。

目前四处职责仍是明确指定的实验需求，非通用内容导演；没有实现任意自然语言创意自动落地、自由形状嵌入、自动趣味认可或质量多样性生产准入。首次15份父图内容复用、4份新版本适配，全部重新验证，未继承旧版本“通过”结论。

完整生成/冻结/21路线验证约137.36秒，属于离线Python+Godot进程+完整轨迹IO。旧CP-SAT布局在本轮复放，没有计入重新求解成本。正式生成器的毫秒数与这个数不是同规模Runtime基准，未据此签Runtime性能。

## 取其精华的下一步

**优先把内容配方提升为导演能安排的体验段，而不是继续增加空地图节点。**

1. 从主游戏提取真实可执行的配方与接口，先保留少量不同操作关系：方向/射线选择、击中回充、机关改变路径、危险下的落点选择。原型审核要看实际回放和便宜替代策略，不能按名字或数量算多样性。
2. 给每条路线明确内容序列：引入→变化→组合→恢复；奖励远征加深同一技巧，替代路线改变主要决策，回程利用已改变的世界。约束“相邻最多重复一次同关系”“本路线与另一条路线的主要决策要不同”，而非只约束房间数。
3. 先由动作核提出真实净空、可见目标、恢复岸和动态扫掠，再求Macro形状/端口与地图嵌入。放不下就回报空间缺口，让导演换模块、调整局部尺寸或路线，不删挑战。当前四处补丁只证明接入链条可运行。
4. 与主游戏统一收益、恢复和生态职责：主线引入可恢复失误，长奖励路在难点前后设置有用的恢复和收益；正式敌人/Boss/跨图状态单独接入重验。
5. 只有一个内容驱动整图得到视频观感认可后，再扩多个Seed与区域语法，用实际路线差异和重复体验审阅；不先用更大规模掩盖内容不足。
