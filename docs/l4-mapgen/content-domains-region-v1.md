# 全库 Block 适配与43模块真实整图

本轮把7节点小样扩大到真实43实例、47直接接缝、5处分叉汇合、3条奖励折返支路。4条常规连续策略与6次冻结地图后的新输入扰动通过。**规模验证取得进展，但多路线设计验收仍未通过**：空间仍呈五段重复双路，段间单向下落，熟练自动通关约98–128秒，没有达到7–10分钟区域目标；也未实现自由网状探索、实际Boss或主要构筑道具。

## 94份全库适配，不等于94份全部完成

[逐版本账本](../../generation/maps/content-domains-region-v1/inventory.json)记录94/94已处理、**40父版本获得有限接口资格，54仍阻塞**。资格仅覆盖绑定能力、指定方向和实际见证；不代表通用入口状态范围或生产准入。每个父版本只计一次，镜像、加宽端岩、新回程策略不算新创意。

阻塞包含：真实动作轨迹越过声明Port外边界、原多Port非边界接口、未声明反向关系、敌人活动完整包络尚无可靠契约、进阶能力下原案例定义或策略失败。完整原因在版本账本的 `attempts`、`source_qualification` 及对应原始运行中。没有把无法适配的模块伪装成同高穿越或静态敌人。

早期 `all-modules-v2` 49候选/52方向，仅41方向通过；旧守卫拒绝与真实动作失败分开保留。能力适配修订后 `advanced-modules-v1` 4/9，不删除其余失败。单方向通过后还需通过测得的形状/边界审查，所以不能由通过case数反推40版本以外也可拼装。

曾发现父版本与镜像的 `variant_id` 前缀相同，导致轨迹样本错误混合。现按**最长精确所属变体**分配case，并拒绝重复身份；新inventory-v3和最终43实例均在修复后计算。旧inventory-v1/v2保留，不覆盖历史结论。

## Block和直接接缝的具体含义

`joined_block_origin` 根据两个Port所属格、相反法线和局部网格原点计算整数原点；两端边界格相邻，Port世界坐标重合。不是把两个完整Block叠在一起，也没有在缝外补平台。布局和闭环按整数精确比较，像素只用于真实碰撞/开口/动作窄相位。

128格同时容纳岩体与空气，不能把整格空气都当岩体。最终实验启用 `allow_shared_air=True`：允许两个128格中的空气预留相交，以32格的实体包络先筛，再检查真实岩体、全动态扫掠和双方身体轨迹；外来单向平台也不能阻挡邻居动作。旧CSP默认仍是独占128格。这里不是“所有Module的完整128格必须互斥”的分区铺满算法；若将来要求整格独占，需要另外生产相应形状，不能声称本实验已满足该更强条件。

新增的身体预留有16px采样外扩，但只代表有限轨迹，不是全部可能操作。剩余链位移使用有界集合DP检查几何闭合；超过4096个集合状态则退回保守区间过滤，不截断成假阴性。全图最终采用1797次展开、一次成功布局，CSP约0.458秒；这是已预处理库存下的一张离线布局，非全生成流程Runtime成本。

加宽变体只延伸原端部岩体，保持挑战输入并重新验；上下换层用直接N/S端口。新 `map_failure_boundary` 变体去除远低于实测动作、且不承载Port/目标/奖励的宽兜底岩体及其附属危险物，**确实改变失败恢复边界**，不继承原难度/可玩结论。五个变体分别再验，随后整图再验；原版本保持不变。

## 43实例的实际内容与路线

全图30穿越挑战槽、10地貌枢纽、3奖励挑战；实际选中15个父版本（11个来自原94库，4个为新增地貌枢纽父版），10种family标签，其中包含新枢纽标签，不能称为15种创意或43个原创Module。挑战槽来自全库条件查询，当前平原只用移动、单跳、反冲；没有为了“全部接入”把钩索锁或来源不明的方向塞进主路。

5段各有上/下两条路径，允许段内低路逆行，最后在J节点真实汇合；下一段通过单向下落进入。5次二选一最多32种组合，不是32张拓扑。主线0宝箱；R0/R2/R4各18金币、沿原挑战返回，同属needle-cache-foldback家族。无商店、主要道具、恢复预算或真实Boss，仅区域出口地标。

Map补地形0、连接Module0、薄单向平台0；202静态碰撞块、5移动齿轮、0移动平台。仍然有许多矩形岩岸和较长安全地面；“没有补平台”并未自动带来协调地貌。

旧7节点小样常规5/5，但后续留出8/11，含动作失败和身体越界；原件完整保留，并通过现有technical-withdrawal机制撤回那7个地图上下文payload的复用资格，未撤回原94父版本。17节点中间样品4/4不计为最终43实例的新留出。

## 录像、性能与复现

低路完整MP4为98.917秒、5870物理帧；奖励支路→原路回程→高路→首次汇合片段24.283秒、1392物理帧，**发生在同一43实例世界中**，不是另一个单Module场景。两片均1280×720/60Hz/正常1倍，含启动、全部等待和末尾1秒，7262物理帧严格一致。原生JSON、录像命令和比较结果归档；AVI在严格对照及MP4 SHA/ffprobe通过后才按回执移除。

低路影片用软件llvmpipe录制约383秒，平均CPU23.7ms/GPU24.93ms、AVI编码15.04ms；这是离线软件渲染与捕获成本，不能据文件60fps声称游戏Runtime达60fps。最终四条无画面验证总319秒，整图生成前的全库单体再验另计。当前未证明运行时即时创作适合上线。

43/43相同硬需求均能从现有隔离候选库取回对应版本，原证据与运行源逐项校验通过；这只是库存检索复验，不是新布局或新整图物理通过。

原始成功、所有校准失败、旧样片、真实输入/压缩trace、冻结源、候选入库记录、发布失败与恢复均在 **content-domains-v1** 归档，共50,134路径/3,450唯一对象、168,617,261字节、17分片；逐文件/分片/整包哈希见manifest。媒体另有13文件/93,689,359字节的不可变公开字节核验，部署成功后真实公网WebGL键盘输入、射击、重试和整图查看smoke通过（43节点/202碰撞块），不是人工试玩。恢复后重跑新名字，禁止覆盖既有批次：

`region-scale-v1/protocol.json`保存来源和预算，`region_run.py`可按同seed/来源复跑原43实例；`region-held-v1`保存冻结后扰动流。目录的编译结果、Module标准文档和recipe为已发生的拼装证据。通用generationContract关系仍UNKNOWN、人工认可0、生产准入关闭。最新代码检查为68 Map、26 factory、19 plains单元检查及npm check通过；这些不代替真实物理批次。

## 下一轮的设计门槛

本轮扩大了可运行世界和已验证接口覆盖，尚不能宣称胜过正式地图或达到空洞骑士区域感。下一轮不再只增加节点：先让区域级跨段回环、不同位置的汇合和可返回的竖向路线进入**同一张图与同一物理求解**，拒绝把五个相似二选一串起来当充分非线性。新增不对称多Port地貌、长奖励挑战与不同奖励职责，减少重复枢纽、低路长行走和整段水平岩岸；再以实际多Seed拓扑、内容/地貌重复、回程收益、真实耗时和用户录像观感共同验收。40～65实例只是规模约束，不是质量结论。
