# 同图驱动的 Map 物化原型 v1

本轮已产出可实际运行的一张风铃平原 Map：22 Macro 放置、24实际 Module 组件、24直接接缝，2条主路和折返/单向环回/汇合三类奖励支路；实际构筑道具、恢复、商店和原游戏 Bellstrider。**它是小规模接口样图，尚未达到40–65实例完整区域或稳定多Seed产出，也未通过美感/趣味验收。**

此前五段分叉串联及专用选型/路线/展示入口保持删除。本轮不恢复任何固定区域骨架；现有 `region_network` 的同一张图传入选型、原空间搜索、实际拼装及所有路线。

## 执行路径

`block_grid.plan` → 原 R2 Mission/Exploration → `graph_map.domains` → `graph_map.joint` → 原 `shape_search.search` → `graph_map.boundaries` → 标准文档 `export_reload` → 原 `direct_join.assemble/audit` → `graph_map.cases` → 原真实 Harness → `block_grid.verify` → CandidateLibrary。

- 全部已验证源按端口数、实际有向关系、能力、明确要求的玩法标签建立候选域；不按节点名、上下层、家族名单挑固定配方。实际Boss职责需要真实Boss合同，普通奖励房不能冒充。
- 高度、朝向、不规则轮廓、碰撞、动态扫掠和实际动作净空参与同一CSP。高阶节点可展开为本地三口组件联合搜索，然后显式折回原Macro节点；不改区域探索图。
- Block128用于整数位置、相邻单元端口重合及闭环约束。粗格子共享空气时仍检查所有邻居实体/危险/动态和身体净空，不把粗格相交自动判安全。
- 新增三角环的端口法线/轮廓/位移约束传播，以及经过未放置枢纽的有限路径位移检查；它们拒绝不可能的几何闭合，不删除设计职责。传统对齐双出口无法实现部分三角回路，增加预算没有帮助，因此经现有工坊生成并真实验证错位同面口/凹轮廓等补缺。
- 每次完整空间候选还必须通过Macro折回、边界条件门体安装；失败继续有限回溯。搜索有节点、几何探针及墙钟预算，失败输出 needs_design，不补连接平台。CP-SAT实验保留，但当前默认使用有真实样图证据的原CSP。
- 只能消费现有基本平原 grounded_dock 状态接口。高速空中无停靠、钩索等尚未提供合格合同，不能宣称已通用支持。

## 失败与修正

全部失败保留，不把重测成功改写成首轮全绿。

1. 新模块矩阵最初包含不完整批次、同一父ID前缀混淆风险：资格检查要求每个自己声明的输入案例都存在且通过；中断批次不进域。
2. 原库存汇总遗漏已有非同高/同侧地貌接口。重新从其独立Module原件提取真实有向矩阵并验证，不恢复其历史固定Map布局。
3. 初次整图v1仅4/10验收：3条实际路线在同Module两个共面支撑交界被旧单一support声明拒绝；另3条被“无限端口平面”误报。适配仅允许同Module、同目标高度、目标附近的明确支撑并集；不改坐标/输入，也不允许邻居或其他高度代偿。接缝测量限定显式 seam_transfer，内部穿越另验身体不离本Module保留形状，不能只取消检查。
4. Boss初次发生地面射击反冲坠落。工坊Boss原型增加自身岩体支撑，重新真实验证；没有改原Boss/角色物理。
5. 首次门体适配试图把知识条件装成机械门，实际放不下。条件类型明确化后仍有4个真实硬门，不伪称知识线索提供物理锁。
6. 多轮空间预算失败、源中断及全部新Seed失败均保留。凹轮廓和传播改善了一张样图的可行性，不足以宣布稳定产出。

## 仍未达到的要求及下一步

- **区域规模和新Seed稳定性未通过。** 固定输入整图的10/10不是生成成功率；看 `graph-map-bounded-seeds-v1` 的全部独立种子与有界失败，不能只给成功种子。
- **内容/美感未通过。** 实际整图仍有重复台阶、长岩台、挑战分布不均。主路没有充分的可执行动作密度/配方要求，宽松候选域会优先解决几何可拼性；必须由Director写入动作职责，并联合选择完整挑战与地貌Macro。不能继续用更多普通台阶库存充当趣味提升。
- 泛化条件门/实际锁能力组合、全图便宜绕过、动态变化下的所有动作状态仍缺系统覆盖；有限具体策略不是无Softlock全证明。
- 主要道具数量和金币预算已有限且真实服务接入，但价值/风险/人类完成成本未标定。恢复和部分小奖励展示仍可改善。
- 多组件Macro具有运行来源/映射；标准输出当前以扁平Module承载，其完整可解析L3子合同导出仍未实现，不将生成参数中的lineage当成正式resolved Macro合同。
- 自增长已实际补过错位口/地貌/真实Boss等缺口，并验证后供Map使用；当前不是能实现任意自然语言创意的通用生成器。独立新源的完整自动候选入库/人工趣味认可仍需补齐。

优先改的是职责约束和多口/高差挑战候选供给、位置与内容联合搜索的成功率、连续岩体构图筛查；之后用同一套完整区域策略扩容并与正式地图同口径比较。不得恢复被删除骨架，也不得用扩大空白或拆碎落脚点凑40实例。

## 运行

```sh
# 现有R2区域设计；不保证当前库存可物化每张设计
python3 -m pcg.map_directed.block_grid.plan --name fresh-region-plan --seed my-seed
# sources取某次不可变protocol.json中的整个sources数组；不挑家族名单
python3 -m pcg.map_directed.graph_map.run --name fresh-map --plan pcg/results/fresh-region-plan --sources <all-qualified-source-runs> --attempts 4 --seconds 60
# 固定预声明新种子，全部有界结果均报告
python3 -m pcg.map_directed.graph_map.experiment --name fresh-seed-audit --source-protocol pcg/results/graph-map-whole-evaluation-v2/protocol.json
python3 -m unittest discover -s pcg/map_directed/tests -v
```
