# 反冲平原：库现状与持续创作方法

用户已对上一批20项给出“这20个大体上都是ok的”整体视频正向意见。当前工作收窄为平原：移动、普通单跳，唯一特殊能力为射击反冲。敌人、风铃、门、载台和危险仍可使用；墙跳、二跳和钩索内容保留供其他区域复用。原话、20个准确版本及视频SHA已记录到 [反馈](../../pcg/feedback/workshop/creative20-positive-video-v1.json)，没有编造单项评分或亲自试玩。

平原视图目前选择 **32个候选版本**，排除9个高级能力版本、1个节奏暂扣、2个未优选旧实验。它是原库的能力/职责索引，没有创建另一个候选库。32个也不代表32种独立玩法，或32个可以随意拼接的房间。

编辑器另有177个参考模块，来源74d8a06；当前物理候选基线12f6cb0。参考库继续保留，技术证据没有混用。

## 11种兼容不等于11种反冲课

M07/M08发布见证没有射击；M12主要是开桥撤掉支撑，M19主要是操作顺序。M09/M10/M11/M13丰富射击与世界的关系，但还不能由“有开枪”推出反冲移动是必要判断。M16/M17/M20可作较复杂的组合候选，教学价值需单独设计。

因此，原六类反冲关系作为当前核心配方；新内容按躲避、射击改世界、探索折返、敌人落位、组合等职责辅助平原。先补宽容的首次反冲教学与实际重试，再逐层引入组合、奖励和回程。[独立模型审视](../../pcg/creative-production/plains-method-review-v1.md)列出了具体工单及尚未完成的方法验收。

## 可持续的方法

采用 [固定平原流程](../../.agents/skills/pcg-creative-producer/references/plains-recoil-workflow.md)：

1. 从地图或人工需求明确这段内容承担教学、练习、组合、奖励、回程恢复中的哪项职责，以及能力、空间、端口、资源和失败成本。
2. 大模型基于现有库与失败提出少量有因果关系的假设；缺口明确返回。将可实现假设写成有参数域、因果不变量、控制搜索和反例的配方。
3. 程序使用同一配方响应不同空间，而非逐房间复制生成器；固定预算搜索，复用原物理和质量筛选。
4. 校准后冻结方案与精确见证，再做独立留出、针对性绕法和适用的恢复。未知方向和状态保留UNKNOWN。
5. 用真实短视频收反馈，按具体问题修订；保留正向内容，修订后重新绑定版本和证据。
6. 原库入库、新进程精确复用；不同需求拒用。同源失败持久化，避免不断重试相同坏点子。

现有工具已经能完成这条闭环。当前要验证的是配方跨空间的适应与反馈后的维护，不能只继续增加样品数量。多数新20项目前只有一个冻结接口，旧六家族也主要是两个已知接口；还不能宣布任意需求稳定生产。

## 本轮实际方法试验

先用两个既有核心关系：尖刺净空反冲、落沿刹车。源码、参数域、四个控制候选、预算及选择规则在执行前固定；输入四个新增Challenge Specification：

|需求|改变的空间条件|结果|
|---|---|---|
|P1|尖刺通道接收前缘475、地面430|regular通过|
|P2|接收前缘505、地面438|regular通过|
|P3|岩沿250、接收地面453、出口x100|regular通过|
|P4|岩沿246、接收地面466、出口x115|regular通过|

原production_loop完成小筛、逐实际身体/机关/资源验证、反例、校准与独立噪声留出；源码未在四需求之间修改，未事后降门槛。4个适配全部入库，冷批约124.6秒；随后新进程4/4原库复用、0新物理调用，约11秒。新的标准需求入口再次4/4复用、0新物理调用。其产出是4个接口适配，新增动作家族为0。

[10秒完整原速拼接](../../generation/workshop/plains-recoil-v1/adaptation-four.mp4)含四段实际Godot录像，每段原生逐帧严格比较通过，共350帧；每段末尾的1秒冻结保留。这些新适配的人工观感尚未评，上一批20项的正向意见不会自动套用到它们。

这些是预先列出的新增空间需求，使用原内层校准/留出种子；它们不是盲揭示的空间留出。独立噪声留出只说明各新实例的局部容错。**本轮验证了局部适配与复用，方法稳定性仍未完成验收。**后续应冻结规则后再揭示多规则、多种空间需求，并检查真实问题反馈后的修订、旧回归和新空间结果；每个入库实例仍执行原regular门槛。

## 已可执行的入口

先恢复原20批证据与本批归拢/新实验；引擎安装与运行时见原工坊README。新归档只恢复实验原件和必要旧依赖，不覆盖当前生成器源码：

```sh
python3 pcg/tools/restore_archive.py content-workshop-creative20-v1 --extract --prefix results/
python3 pcg/tools/restore_archive.py content-workshop-plains-method-v1 --extract

# 查看当前原库的反冲平原视图
python3 -m pcg.prototype.creative_batches.plains_workshop.catalog_v1

# 读取完整Map Challenge Specification，精确检索；不放行UNKNOWN拼装
python3 -m pcg.prototype.creative_batches.plains_workshop.catalog_v1 --query demand.json

# 导出当前两个有界配方的需求示例，再经统一入口生成/复用
python3 -m pcg.prototype.creative_batches.plains_workshop.produce_v1 --examples > demands.json
python3 -m pcg.prototype.creative_batches.plains_workshop.produce_v1 --name fresh-plains-demand --specifications demands.json
```

该入口当前注册两条有界适配配方；其他关系按其具体已实现规则处理。输入超出能力、空间、端口、资源或回程支持域时返回冲突与可协商条件，不替换成普通房间。完整原库检索与标准文档的SHA验证继续由原CandidateLibrary/WorkshopLibrary承担。

接下来内容工作依次补安全教学、反冲控制练习、已教动作的世界组合、可选奖励与真实回程恢复。配方接受B现有平原需求，由B负责探索拓扑、空间布局、接缝与整图验收。最终目标是一块内容充实、可探索的反冲平原；本轮库归拢和四个小试件只是这个目标的内容基础。
