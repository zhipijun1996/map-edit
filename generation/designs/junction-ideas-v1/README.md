## J01 钟柱环岛

上台后在第一个高岸离台，还是保持承载绕过钟柱、在后一个低岸离开；必要时主动走位或暂停，不能靠站定长等一整圈作为唯一玩法。

![钟柱环岛概念示意](J01.svg)

## J02 折脊分水岭

从共享观察肩选择保高度走脊上，还是主动降入岩腹、借反冲刹向侧通道。两条路都继续探索，不以一条宝箱死路配一条安全路。

![折脊分水岭概念示意](J02.svg)

## J03 交织双桥

从高层继续向东，还是在中庭降到低廊；从低层进入时可留在低路或投入一枪抬升换到高桥。

![交织双桥概念示意](J03.svg)

## J04 扇门前庭

选西翼B时，瞄东侧的B门接收铃，打开西门并向西反冲；选东翼C时，瞄西侧的C门接收铃，打开东门并向东反冲。先开过两门时也应保留左右地貌和地区去向的选择。

![扇门前庭概念示意](J04.svg)

## J05 顺流石井

保住中层高度去B，继续下降后去C，或在另一个可读窗口反向制动去D。决定是沿下落过程逐步承诺，不是失败后自动分配一个安全出口。

![顺流石井概念示意](J05.svg)

## J06 双岸会合风口

从高口A进入时，向东C继续还是下到B接另一条低层地区路；从B进入时，主要任务是利用地形抬升到C。这里可以是平静、低强度的地区节点。

![双岸会合风口概念示意](J06.svg)

建议先比较J06静态方向型节点与J03错层换乘，再单独评估J01环绕Cell的真实承载成本。
