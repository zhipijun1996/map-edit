已实现候选和已归档有什么区别？

已实现候选：已有真实 Module 和限定范围的验证结果，当前仍在独立实现分支，等待版本对齐、集成和归档。

已归档：具体版本已纳入主库目录，资源、接口与证据可统一检索复用。归档不自动代表真人试玩、所有接缝或整图验收通过。

你保留的图稿先进入“待实现”，实际实现与验证完成后才成为候选。
