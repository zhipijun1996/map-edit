# Block128 disk reuse v7

The original `catalog_v2` and persistent `CandidateLibrary` were invoked in 7 independent Python processes against the published 22-version manifest. One unchanged, full Challenge Specification retrieved the expected N12 immutable version. No generator or physics was called. Together with the preserved earlier receipts this records 22 reused Block candidates.

The N12 request was independently changed in six ways: Block256, one-Block narrower space, a north-facing first port, an unverified falling entry state, automatic seam resource reset, and a major traversal-item reward. All 6 changed requests returned `unsatisfied` with search scope/conflicts. This is evidence that unsupported adaptation is rejected; it is not a proof that a new implementation could never satisfy it.

`receipt.json` binds every request, response, manifest, original record, prior receipt, and original query-source hash. Each response is also saved separately; the receipt contains the exact reproduction command. No original source, candidate record, or physical evidence was modified.
