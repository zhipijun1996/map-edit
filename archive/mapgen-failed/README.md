## 为什么终止

旧管线虽有有限可玩样图，却没有实现用户要求的稳定、高质量多路线探索地图。22 Macro样图有10/10有限整图路线和9/9有限反向探针通过；另外3个预定新Seed空间搜索全部失败。技术见证不能证明趣味、美感或稳定产出。

根本问题包括：图的玩法职责不足、过早锁定结构、实际挑战接入不足、重复岩台与枢纽、默认落地入口、强制用满Port、三口组件树式包装，以及地图拼装期间适配地形和添加状态门。它们与新地基中的矩形占用、部分Port启用及认证封口、完整实际Port有向图、静态在线能力过滤及离线内容发布边界冲突。

失败不是对所有Module的否定。单Module的真实物理证据仍在原版本和原覆盖范围内有效；不自动满足新地基，也不自动获得通用接缝、回程、镜像、生产或人工趣味认证。

## 当前隔离边界

- 旧Map可执行目录、目录外专用生成器/适配器、工作Skill与CI入口退出当前工作区，不保留导入别名、legacy开关或算法回退。
- 94份Module候选、282个原件文件逐字节迁至 `pcg/module_library/store/candidates/`，不改内容版本和审核状态。
- 旧Map实例和具体Map上下文载荷的162个记录文件放在 `library/`，不能用作Module库根目录。
- 中立库仅提供候选管理、原证据校验、撤回和现有离线配方的精确匹配；不包含探索图、空间求解或Map入库API。
- 保留的载台挑战读取固定离线夹具；配方特有的尺寸/端口/状态不是新Module通用设计规则。
- 历史文档、结果、录像和冻结源快照保留原始身份，不作为当前工作指令或导入目录。主游戏原件未修改。

## 历史查阅与证据恢复

历史代码只能在**独立目录的历史检出**中查阅，不能恢复到当前工作区：

```sh
git worktree add --detach /tmp/mapgen-history 862b736c491502ae9934265bc7415805b4c122b9
```

这是人工查阅说明，不是Module流程或自动失败回退。

旧完整归档仍保持原字节。归档恢复工具会拒绝向已退役或已迁移位置写回文件。Module候选所需的最小原证据另有 `module-library-evidence-v1`，只包含数据，不包含旧Map源码；可单独恢复，不必恢复任何Map系统。

静态报告/录像仍可访问，但展示入口标明“已终止历史实验”。本仓库不继续修复此Map生成器；新Map在独立仓库按用户规范实现。
